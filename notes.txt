sword grpo training engine: refactoring and architecture notes

2026-10-25: GRPO/bridge/Model B/scorer/vLLM bug audit and fixes are recorded in GRPO_AUDIT.md.
It includes verified regressions, OOM rollback handling, and remaining hardware-validation limits.

1. overview and requirements
- goal: build a clean, unified, robust grpo training architecture for sword.
- single entry point: sword.train(long_train=True, test=False, ...) with all specified parameters.
- infinity dataset handling: sha-256 deduplication via data_complete.logs to prevent retraining on stale data.
- agentic harness integration: vendor/integrate open harness wrappers (opencode, codex cli, gemini cli, pi) into sword.
- custom multi-reward system:
  * attributes: problem, solution, reasoning_rule, answer_rule, can_be_verify, difficult, category, harness.
  * metrics: truth, formatted, rule_reasoning_follow, rule_answer_follow, tools_success, cheating.
- model b ollama judge:
  * communicate over http with ollama server on custom port (e.g. 11343).
  * structured json/yaml evaluation prompt and robust parsing.
- resilience and memory safety:
  * try/except blocks for graceful degradation.
  * out-of-memory detection with automatic cache clearing, retry, and emergency checkpoint save/upload.
  * custom checkpoint saver independent of unsloth saving with read-back verification.
  * hugging face automatic repo creation and resumable checkpoint tracking.
- testability:
  * mock/cpu test suite verifying all code paths without requiring live gpus or external servers.

2. planned modules in sword
- sword/trainer_config.py: configuration dataclasses for training, lora, arguments, and dataset specs.
- sword/b_model.py: ollama model b client, prompt generator, structured score parser, and vram lifecycle manager.
- sword/harness/: vendor / adapter layer for agentic harnesses (opencode, codex, gemini, pi) tracking multi-turn interactions.
- sword/reward.py: multi-metric reward calculator combining ground truth math verification, formatting, model b rules, and tool metrics.
- sword/checkpoint.py: custom checkpoint serializer, read-back verification, sha-256 dataset tracking, resume discovery, and hugging face hub synchronizer.
- sword/long_trainer.py: infinite grpo training loop coordinating rollout, model b scoring, chunked training, and memory lifecycle.
- sword/train_entry.py: updated unified sword.train entry point routing cleanly to test or long_train.
